# Base de Dados Jurídica com o Repositório CTRESB/Leis

Este projeto documenta como utilizar o repositório ctresb/leis como base de dados para consultas jurídicas, sistemas RAG (Retrieval-Augmented Generation), IA generativa, motores de busca e aplicações web. 【1-35c3da】

## Sobre o Projeto

O repositório ctresb/leis disponibiliza a legislação brasileira em formato Markdown, organizada por esfera governamental, tipo de norma e ano. A estrutura inclui Constituição Federal, leis federais e legislação estadual. 【1-35c3da】

## Pré-requisitos

Instale:

- Git
- Python 3.11+
- Visual Studio Code (opcional)
- PostgreSQL (opcional)
- Docker (opcional)
- Ollama (opcional)
